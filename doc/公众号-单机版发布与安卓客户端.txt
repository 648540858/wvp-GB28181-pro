WVP-PRO 单机版发布：不装 MySQL、不装 Redis，也能跑起国标视频平台

一直以来，WVP-PRO 的部署需要 MySQL、Redis 和 ZLMediaKit 等组件配合，还要逐项核对配置。新版本增加了单机部署模式，把这些依赖做成了可选项。

一、单机版：不装 MySQL、不装 Redis 也能运行

数据库不再是必选项。删除配置文件中 spring.datasource 相关配置后，WVP-PRO 会自动启用内置的 H2 文件数据库，首次启动自动建表并初始化数据，不需要安装 MySQL，也不需要手工执行 SQL。数据库文件默认保存在 data 目录下。

Redis 同样不再是必选项。删除 spring.data.redis 相关配置后，系统会启用内置 Redis，设备缓存、订阅关系和消息总线都在进程内完成，行为与集群模式保持一致。

也就是说，只需要删除 MySQL 和 Redis 相关配置，就能直接使用默认的 H2 数据库和内置 Redis。已经部署了 MySQL、Redis 的环境不需要改动，保留原有配置即继续使用真实数据库和 Redis，多节点集群部署方式也完整保留。

单机模式默认使用 standalone 配置。Docker 部署只需构建镜像、准备配置目录，然后执行 docker compose up -d，WVP 与 ZLMediaKit 会一起启动；数据、录像、日志、配置分别挂载到独立目录，升级时替换镜像即可。构建脚本支持跳过前端构建或跳过 jar 构建，方便复用已有产物。

二、系统设置：配置在页面修改

「系统设置」按业务拆成四个面板：WEB 服务、国标服务、部标服务、全局策略。端口、HTTPS 证书、SIP 编号与域、JT808/1078 服务参数、订阅与鉴权策略，都可以在页面上修改、校验并保存。

需要重启才能生效的字段会明确标注，这个重启标识也可以按需隐藏；确实需要重启时，直接在页面触发。能够热生效的配置在保存后立即应用，不需要重启整个平台。

配置文件本身也可以管理：查看当前生效的档案、在线浏览配置内容、在不同 profile 之间切换。

三、扫码接入

设备接入信息页重新调整了布局，展示国标编号、域、IP、端口和密码，并生成接入二维码，同时提供一键复制。多网卡环境下，可用 IP 会分行列出。

配套的国标设备端客户端可以扫描二维码导入平台配置，不需要逐项填写地址、端口、域和密码。

四、配套安卓客户端

同步推出的安卓客户端是一套 GB/T 28181-2022 设备端实现，采用记录仪形态的演示界面，用于验证平台侧的注册、目录、点播、录像、回放、下载、对讲与报警链路。

覆盖能力包括：注册与 Digest 认证、心跳、目录与设备信息应答、实时点播、TCP 媒体主被动模式、本地录像与检索、历史回放与倍速/seek/倒播、录像下载、语音广播与对讲、预置位与云台指令解析、报警上报与报警联动录像、远程重启与远程升级，以及移动位置订阅、存储卡状态、OSD、画面翻转、遮挡、视频参数等设备配置能力。协议版本为 2022，支持 GB18030 中文编码、H.265 与 AAC。

客户端内置移动侦测、区域入侵、绊线、徘徊等视频侦测能力，可选开启轻量目标检测模型，并把检测框叠加到推流画面。

与 WVP-PRO 联调分三步：在平台生成接入二维码，在客户端扫码导入，确认设备国标 ID 后启动。平台侧可以看到设备在线、通道可点播，之后再逐项验证回放、下载、对讲和报警。

五、升级说明

使用 MySQL/Redis 部署的环境可以直接升级，原有配置和数据结构继续有效。切换到单机模式时，删除 MySQL 和 Redis 相关配置，让系统使用默认的 H2 数据库和内置 Redis 即可。生产环境需要修改默认账号密码，并只对可信网段开放 SIP 与媒体端口。
